# instant-film-agent

画像に実在するインスタント写真（instax mini / Polaroid 600 / SX-70 / instax WIDE）の精密な物理フレーム、0〜100の化学現像エミュレーション、および余白への手書き文字（書き手の個性・インク物理質感）と日時を合成する道具を、AIエージェントから使うための手続き。

## 道具

- コマンド: `instant-film-agent`（または `python -m instant_film_agent`）
- 導入確認: `instant-film-agent doctor` が全項目 `[OK]` であること
- プリセット: `favorite`（お気に入り）が既定。実体は `favorites.json` が決める（初期値は `instax-mini`：縦長チェキ実寸、白枠、ハイキートーン、日常日記ペン）。

## トリガー語（こんな指示があったら発動）

- 「チェキ風にして」「チェキの写真にして」「instax風に枠をつけて」
- 「ポラロイド風にして」「ポラロイドの枠をつけて」「ポラ風写真にして」
- 「インスタントカメラ風にして」「インスタントフィルム風に現像して」
- 「余白に手書きで文字を書いて」「サインやタイトルを入れて」
- 「写真の余白に日付を入れて」「撮影日を手書きで入れて」
- 「エモいインスタント写真にして」「ヴィンテージポラロイドにして」
- 画像を生成・加工した直後に「チェキにして」「ポラロイドにして」と言われた場合も対象

## 実行手順

1. **対象画像の特定**:
   - 会話の中で言及されている画像、または直前に生成・編集した画像を特定する。

2. **プリセットとパラメータの選択**:
   - **特に指定がない場合**: 既定のお気に入り（`favorite`）を使用する。
     ```bash
     instant-film-agent apply <対象画像> --json
     ```
   - **世界観や時代・スタイルの指定がある場合**:
     - 「チェキ風」「縦長チェキ」: `-p instax-mini`（縦長3:4、清潔なハイキー人肌トーン、日記ペン）
     - 「ポラロイド風」「正方形ポラ」: `-p polaroid-600`（正方形1:1、90s青緑黒浮き、太字メモ）
     - 「70年代」「SX-70」「レトロポラ」: `-p polaroid-sx70`（正方形1:1、濃厚な琥珀色暖色トーン、温白色用紙、万年筆）
     - 「ワイド」「横長パノラマ」: `-p instax-wide`（横長16:10、青インク）
     - 「パステル」「かわいい」「アイドルチェキ」: `-p pastel-dream`（軟調白浮き、丸文字、銀ラメペン）
     - 「夏」「鮮やか」「ロモ風」: `-p vivid-summer`（高彩度・高コントラスト、赤マーカー）
     - 「モノクロ」「白黒ポラ」: `-p classic-monochrome`（純銀塩モノクロ、温黒調、筆文字）
     - 「夜景」「エモい」「映画調」: `-p cinematic-night`（黒台紙フレーム、ティール黒浮き、白ポスカ）
     - 「古い」「アンティーク」: `-p aged-nostalgia`（経年劣化用紙、色褪せ、アンティーク万年筆）
     - 「比率を変えないで」「トリミングなしで」: `-p keep-aspect-clean`
     - 「画像の縦横に合わせて自動で」: `-p auto-smart`

3. **余白テキスト・日付オプションの組み立て**:
   - **キャプションの記入**:
     - 「"〇〇" と書いて」「タイトルを入れて」→ `-c "キャプション文字列"`
   - **日付の選択**:
     - **指定がない場合（既定）**: プリセットの設定に従う。
     - **写真の撮影日時を使いたい場合**: 「撮影日時で」「EXIFの日付で」→ `-d photo`
     - **今日の日付にしたい場合**: 「今日の日付で」→ `-d today`
     - **昔のランダム日付にしたい場合**: 「昔の適当な日付で」→ `-d random`
     - **特定の日時を指定された場合**:
       - 「1999年7月24日にして」→ `--at 1999-07-24` または `-d "'99 07 24"`
     - **日付を印字したくない場合**: 「日付は入れないで」「文字だけで」→ `-d none`

4. **高度なカスタマイズ（指定がある場合のみ）**:
   - **現像強度**:
     - 「色調は変えないで枠だけつけて」→ `--emulation 0`（完全非破壊）
     - 「もっと強く現像味を出して」→ `--emulation 85`
   - **印画紙カラー**:
     - 「黒枠にして」→ `--paper "Matte Black"`
     - 「ヴィンテージ用紙で」→ `--paper "Aged Vintage"`
   - **手書きペン・インク**:
     - 「赤ペンで書いて」→ `--ink "Sign Pen Red (Correction)"`
     - 「白文字で」→ `--ink "White Paint (Correction Pen)"`
     - 「ラメペンで」→ `--ink "Silver Gel (Glitter)"`
     - 「丸文字で」→ `--style "Cute Round Pop (Kawaii)"`
   - **マスク画像の保存**:
     - 「写真窓のマスクも欲しい」「切り抜きマスクも出して」→ `--save-masks`

5. **結果の報告**:
   - `--json` の出力をパースし、`ok` が true であれば、`output` に格納された画像パスをユーザーに提示・報告する。
   - 適用した構図規格（`frame_format`）、プリセット（`preset_resolved`）、および印字したテキスト（`rendered_text`）を一言添える。
   - 例: *「縦長チェキ風（instax mini）で、余白に手書きキャプション『Summer Vacation | '03 10 02』を記入して仕上げました。」*

6. **エラー時の対応**:
   - 終了コード 2（設定エラー）: `instant-film-agent presets list` で利用可能なプリセットを確認して選び直す。
   - 終了コード 3（入力ファイル不在）: 入力画像のパスを確認する。
   - 終了コード 4（出力重複）: 上書きを求められている場合は `--overwrite` を付与する。
   - 終了コード 5（エンジン失敗）: `instant-film-agent doctor` の結果を確認してユーザーに報告する。

## 「どんなことができるの？」と聞かれたら

1. `instant-film-agent capabilities --json` を実行し、能力カタログに基づいて答える。
2. 説明の要点:
   - 実在するインスタントカメラ（チェキ縦長、ポラロイド600正方形、SX-70、チェキワイド）の実測比率フレーム。
   - 0〜100 の光学・化学現像エミュレーション（ハイキートーン、70s暖色、90s青緑、パステル、モノクロ、映画調など）。0にすれば元画像の色を完全維持可能。
   - 余白へのリアルな手書き文字（20種類の本格手書きフォント、油性ペン・万年筆・ラメペン・白ポスカ等のインク物理再現）。
   - 写真のEXIF撮影日時、今日の日付、ランダム過去日付の自動抽出・印字。
   - 写真窓やカード外枠のマスク出力対応。

## 守ること

- 元画像を直接上書きしない（`-o` に入力画像と同じパスを指定しない）。
- 報告は JSON の `output` を正とする。推測でファイル名を答えない。
